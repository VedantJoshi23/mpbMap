# Etak

An Android app that reskins real-world maps in original, game-inspired
styles. Its headline utility is a location-based arrival alarm that wakes
travellers as they approach their stop. The concept is inspired by
[MapShifter](https://mapshifter.com/) (iOS) by Filipp Bazun. This project
is independent and is not affiliated with MapShifter.

The project is spec-first and governed by
[Oriveda](https://github.com/VedantJoshi23/Oriveda). Its specifications
live in [`knowledge/`](knowledge/). Start with
[`CLAUDE.md`](CLAUDE.md) and the evidence log.
